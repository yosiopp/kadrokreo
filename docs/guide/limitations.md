# 未対応

[ユーザーズガイド](README.md) の一部。今はできないこと。

- 線に沿う文字（`textPath`）
- テキストのアウトライン化とテキストを入れたブーリアン演算は、kdr に埋め込んだ書体のテキストだけ（OS の書体の字の形は読めない）。合字などの字の置き換え・書体に無い太さを太字に見せかける描き方・書体に無い文字の補いは再現しない。WOFF2 の書体は取り込めないので対象外
- マスクの当たり判定は、不透明度・明るさのマスクでも形（テキストは文字の形、画像・フレームは枠）で決める（透けている所や、画像の透明な所でも当たる）
- viewer の CSS で、画像を含むマスクの `mask-image` は画像を data URI で埋め込む（長くなる）
- SVG の取り込みで表せないもの（図形がいくつもあるグラデーションのマスク（形だけかける）、フィルタ、`textPath`（文字はまっすぐ並べる）、外部の画像、`:has()` や疑似要素などの CSS のセレクタ、`stroke-miterlimit`、傾けた円形のグラデーション）
- SVG 書き出しのフォントは埋め込まず名前だけ（開く環境に書体がなければ別の書体になる。kdr に埋め込んだ書体も SVG には入らない）。viewer の HTML・CSS のコードにも、埋め込んだ書体の `@font-face` は入らない。WOFF2 の書体は取り込めない。文字の基線は書き出した環境の書体の高さで置くので、別の環境で取り込み直すと書体の高さの違いだけ上下にずれることがある。1 行だけのテキストは行の高さを読み戻せない（文字の位置は揃う）
- 影ごとの描画モードは viewer の CSS では表せない（ふつうに重ねて書く）。SVG 書き出しでは影を別の要素に分けて混ぜるが、半透明か描画モードを持つ図形では図形の中だけで混ざる
- 半透明のフレームの「通過」は、子が重なるとき SVG・CSS で表せず、中身をまとめてから半透明にする。子が重ならなければ不透明度を子に配って同じ見た目で書く
- 回した図形への吸着（スナップ）は、囲む矩形の端と中央に対してだけ効く。影のずれは回転に従わない
- viewer の CSS の切り抜きの拡大は `object-view-box` で出す（対応していないブラウザでは拡大されない）
- 1 つのテキストの中での部分的な装飾
- インスタンスごとの上書きのうち形や並びに関わるもの（大きさ、位置、行の高さ、行揃えなど）

# 計測（2026-11-24、ドラッグ 1 歩のストアの preview）

`npm run bench` の結果（`bench/out/latest.md` をそのまま写したもの）。値は操作 1 回ぶんのメインスレッドの時間（ms）。測り方は `bench/run.mjs` と `cli/bench/` の先頭のコメント。
その前の移り変わりは `2026-11-22-perf-rest-3.md`・`2026-11-22-perf-rest-2.md`・`2026-11-22-perf-rest.md`・`2026-11-22.md`・`2026-11-22-kdr-tar.md`。

- 環境: darwin arm64、Node v24、Chrome（ヘッドレス）、1440×900、deviceScaleFactor 2。同じマシンで続けて測った（並行して別の処理も動いていたので、値は揺れる。kdr を開く・パン・ズームなど今回触っていない行の差は揺れ）
- 直す前は直前の main（bench は同じもの）で測った

主な行（中央値、ms。medium / large）:

| 操作 | 直す前 | 直した後 | 効いたもの |
| --- | ---: | ---: | --- |
| ドラッグ 1 歩（レイヤーを開いた状態）editor | 6.3 / 20 | 3.6 / 7.3 | 下の全部 |
| ドラッグ 1 歩（ページ直下を閉じた状態）editor | 3.7 / 19 | 3.6 / 8.4 | 同上 |
| ストアの preview 1 回（ドラッグ 1 歩）Node | 1.3 / 13 | 0.33 / 2.5 | 後始末が変わったノードのまわりだけを見る。残りはノードの表の写し（約 2ms） |
| ストアの apply 1 回（settle を含む）Node | 1.3 / 12 | 0.35 / 2.5 | 同上 |

- ノードの表を写して書き換えたとき、変えたノードの id を覚えておく。ストアの後始末（上書きの検出・元の集め直し・辺への追従・演算の枠合わせ・並べ直し・コンポーネントの同期）は、変更の前と後の間で変わったノードだけを見る。
- 同期は、変わったノードの祖先・子・（親が変わったときは）子孫のインスタンスだけを確かめる。元やその中身が変わったときは今までどおり全部を確かめる。
- 読み込んだ直後のドキュメントは、最初の変更のときに一度だけ「並べ直しても同期しても変わらない」ことを確かめ、それからは差分だけを見る（ブラウザのドラッグは読み込んだ直後から始まるので、これがないと毎歩全部を見ていた）。
- ブラウザでは、ドラッグの recipe の親の付け替え（毎歩、木全体をたどって並べていた）、描き直す範囲を決めるための変わったノードの検出、バリアントのまとまりの枠を描くための全ノードの走査も、同じ覚え書きで軽くした。

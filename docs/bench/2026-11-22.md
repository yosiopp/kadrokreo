## 改善後（2026-11-22、性能の改善の 1〜3 を入れたあと）

同じマシンで、直す前に測り直してから、1 つ直すたびに測った。4（`store.select` の不要な通知）は測って要らないと決め、入れていない。

- 環境は上と同じ。`c9e89ae`（kdr v15・パスの曲線・SVG の取り込み）の上に 1〜3 を入れて測った
- この回から、表に「範囲選択 1 歩（選択が変わらない）」を足した（何もない場所の中で行き来する。4 を決めるため）
- `syncComponents（元に関係ない変更）` は、毎回別のドキュメントを作って同期するように測り方を直した（同じ参照だと 3 の覚え書きで飛ばされて 0 になる）。長方形を動かす時間を含む
- `syncComponents（変更なし）` は同じ参照のドキュメントなので、3 の覚え書きで飛ばして 0 になる
